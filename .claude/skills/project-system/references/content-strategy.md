# Content Strategy Reference

Blog posts, marketing content, and content planning.

---

## Blog Post Structure

```
Title (60 chars max for SEO)
↓
Hook (First 2 sentences — grab attention)
↓
Context (Why this matters now)
↓
Promise (What reader will learn)
↓
Body (Sections with H2 headings)
↓
Conclusion (Summary + CTA)
```

---

## Title Formulas

**How-To:**
"How to [Achieve Result] in [Timeframe]"
- "How to Double Your Conversion Rate in 30 Days"

**List:**
"[Number] [Things] to [Achieve Result]"
- "7 CSS Tricks Every Developer Should Know"

**Question:**
"Why [Common Practice] Is [Unexpected Take]?"
- "Why Your Unit Tests Are Slowing You Down"

**Result Story:**
"How [we/I] [achieved specific result]"
- "How We Grew to 10K Users Without Paid Ads"

**Definitive Guide:**
"The Complete Guide to [Topic]"
- "The Complete Guide to React Server Components"

---

## Hook Examples

**Surprising Stat:**
"90% of landing pages convert at less than 5%. Here's how to beat those odds."

**Contrarian Take:**
"Everything you've heard about code reviews is wrong."

**Story:**
"Last month, we shipped a bug that cost us $10,000. Here's what we learned."

**Question:**
"What if you could cut your build time in half?"

## Body Writing

### Section Structure
- H2 for main sections
- H3 for subsections
- 3-4 paragraphs per section
- Include examples, code, or images

### Paragraph Rules
- 2-3 sentences max
- One idea per paragraph
- Transition between paragraphs

### Include
- Code examples (tested)
- Screenshots where helpful
- Real data and examples
- Actionable advice

---

## Content Types

### How-To Guide
```
1. Problem statement (specific)
2. What you'll need
3. Step-by-step instructions
4. Common issues and fixes
5. Expected result
```

### Case Study
```
1. Challenge (specific metrics)
2. What we tried (including failures)
3. Solution (with details)
4. Results (with numbers)
5. Key takeaways
```

### Comparison
```
1. Quick recommendation
2. Feature-by-feature table
3. Pricing comparison
4. Best for each use case
5. Migration notes (if switching)
```

---

## Avoid AI-Sounding Content

**Don't Write:**
- "In today's fast-paced world..."
- "Let's dive in..."
- "Without further ado..."
- "In conclusion..."
- "It's important to note that..."
- "In the ever-evolving landscape..."

**Instead:**
- Jump straight to the point
- Use natural transitions
- End when you're done
- Write like you speak

## Email Content

### Welcome Email
```
Subject: You're in
Body:
  - One sentence: what they can now do
  - One link: most important action
  - One sentence: where to get help
```

### Feature Announcement
```
Subject: [Feature name] is here
Body:
  - What it does (one sentence)
  - Why it matters to them
  - How to use it (screenshot/link)
```

### Re-engagement
```
Subject: We miss you (or specific value prop)
Body:
  - What's new since they left
  - One specific reason to come back
  - Easy CTA
```

## SEO Basics for Content

### On-Page
- Primary keyword in title
- Keyword in first paragraph
- Use related keywords naturally
- Meta description (155 chars)

### Structure
- One H1 (title)
- H2s for main sections
- H3s for subsections
- Short paragraphs

### Links
- 2-3 internal links
- 1-2 external links to authoritative sources
- Descriptive anchor text (not "click here")

## Word Count Guide

| Type | Words | Reading Time |
|------|-------|--------------|
| Quick tip | 500-800 | 2-3 min |
| Standard post | 1,000-1,500 | 4-6 min |
| In-depth guide | 2,000-3,000 | 8-12 min |
| Ultimate guide | 3,000+ | 12+ min |

## Quality Checklist

- [ ] Title is compelling and under 60 chars
- [ ] Hook grabs attention immediately
- [ ] Content delivers on title's promise
- [ ] Includes actionable takeaways
- [ ] Has concrete examples
- [ ] Uses proper heading hierarchy
- [ ] No spelling/grammar errors
- [ ] No AI tells (banned phrases)
- [ ] Links checked and working
- [ ] Meta description written
- [ ] CTA at end
